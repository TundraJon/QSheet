QSheet timing test workbook

Five sheets built to test opening, calculating and switching. It replaces the workbook that is open in QSheet, so export your own first.

Download qsheet-timing-test.json
  1. Open QSheet. In the Data tab tap Export Workbook if you want to keep what you have.
  2. Tap Import Workbook and choose the file you just downloaded. Time how long it takes to appear.
  3. Tap each sheet tab (Big Grid, Calc Heavy, Text and Dates, Looks and Rules, Links and Dice) and time each switch. Do it twice.
  4. On Big Grid change a number, then open Calc Heavy and time it.
  5. On Calc Heavy type a new number in A4 and time how long until the screen settles.
  6. On Links and Dice tap Re-roll (Data tab).
